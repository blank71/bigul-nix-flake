In this section, we demonstrate that
many list functions can be bidirectionalized
using BiGUL. To show the correspondence with the original list functions,
we prefix
the original forward function names with "lens". Note that in our context,
the original forward
functions can be automatically derived from the new putback transformations
by calling \ensuremath{\Varid{get}}.

Simply speaking, \ensuremath{\Varid{lensFoldr}} accepts a putback function \ensuremath{\Varid{bx}} and a
view condition \ensuremath{\Varid{pv}}, and performs the case analysis to put the view \ensuremath{\Varid{v}}
to the source \ensuremath{(\Varid{xs},\Varid{e})}. If the view \ensuremath{\Varid{v}} satisfies \ensuremath{\Varid{pv}}
but the list \ensuremath{\Varid{xs}} in the source is not empty, then it adapts the list to be empty.
If the list \ensuremath{\Varid{xs}} in the source
is empty, we do nothing but using the view to replace the second component of the source.
Otherwise, we rearrange the source from the form of \ensuremath{(\Varid{x}\mathbin{:}\Varid{xs},\Varid{e})} to that of \ensuremath{(\Varid{x},(\Varid{xs},\Varid{e}))}, and
apply \ensuremath{\Varid{lensFoldr}} recursively with a composition with \ensuremath{\Varid{bx}}. One may understand the composition
through the following picture (where \ensuremath{\Varid{r}\mathrel{=}\Conid{Replace}\mathbin{`\Conid{Prod}`}\Varid{lensFoldr}\;\Varid{bx}\;\Varid{pv}}).
\[
(x,(xs,e)) \overset{r}{\leftrightarrow} (x,e')
\overset{bx}{\leftrightarrow} v
\]
