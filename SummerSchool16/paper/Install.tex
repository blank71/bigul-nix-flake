\section{Preparation: installing BiGUL}

The latest version of BiGUL has been released to Hackage. 
To install the package, just run the following two commands.
\begin{verbatim}
> cabal update
> cabal install bigul
\end{verbatim}

Now you can easily check whether BiGUL is correctly installed.
First, create a simple file called ``test.hs'' with the following 
content for importing BiGUL modules.
\begin{verbatim}
{-# LANGUAGE FlexibleContexts, TemplateHaskell, TypeFamilies #-}
import Generics.BiGUL
import Generics.BiGUL.Interpreter
import Generics.BiGUL.TH
import Generics.BiGUL.Lib
\end{verbatim}
Then load it using the GHC interactive interpreter.
\begin{verbatim}
> ghci test.hs
GHCi, version 7.10.3: http://www.haskell.org/ghc/  :? for help
[1 of 1] Compiling Main             ( test.hs, interpreted )
Ok, modules loaded: Main.
\end{verbatim}

If you see the above message, congratulations on your successful installation.
